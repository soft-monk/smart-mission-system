## 1. 运行形态（已实现）

| 项 | 实现 |
|---|---|
| 架构 | B/S：单机服务端 + 多终端浏览器访问，客户端零安装 |
| C++ 服务端 | Drogon，单进程：REST `/api/v1/*` + WebSocket `/ws` + 静态托管（前端/瓦片/视频/报告）+ UDP 组播接入 + SQLite |
| Python AI 桥 | FastAPI，仅监听 `127.0.0.1:8090`，由 C++ 反代 `/api/v1/ai/*`；密钥只在服务端 |
| 前端 | React + TypeScript + Vite + MapLibre GL（二维）；Zustand 状态机；原生 WebSocket |
| 端口 | HTTP/WS `8080`、AI 桥 `8090`、UDP 组播 `239.10.10.10:45454`（均可由环境变量覆盖） |
| 数据 | SQLite `backend/data/mapapp.db`（16 张表，首次启动自动建表并播种两套场景演示数据） |

## 3. REST 接口清单（实测可用，前缀 `/api/v1`）

| 分组 | 端点 |
|---|---|
| 健康与配置 | `GET /health`、`GET /map/config` |
| 场景 | `GET /scenarios`、`POST /scenarios/recommend` |
| 任务 | `POST /missions`、`GET /missions/current`、`GET /missions/{id}`、`PUT /missions/{id}/phase`、`POST /missions/{id}/reset` |
| 资源与编组 | `GET /resources/uavs`、`GET /groups`、`POST /groups/generate` |
| 方案 | `GET /plans`、`POST /plans/{id}/adopt`、`POST /plans/{id}/optimize`、`POST /plans/{id}/confirm` |
| 链路 | `GET /links/topology`、`GET /links/metrics`、`GET /links/curves`、`POST /links/optimize` |
| 目标 | `GET /targets`、`GET /targets/{id}`、`GET /targets/{id}/track`、`POST /targets/{id}/strike`、`POST /targets/{id}/upgrade`、`POST /targets/{id}/watch` |
| 执行 | `GET /execution/status`、`POST /execution/guide`、`POST /execution/replan` |
| 评估与报告 | `GET /assessments`、`GET /reports`、`POST /reports` |
| AI（反代 Python 桥） | `POST /ai/chat`、`POST /ai/stt`、`POST /ai/tts`、`GET /ai/health` |
| 媒体 | `GET /media/videos` |
| 静态 | `/`（前端）、`/tiles/**`、`/media/**`、`/reports/**`（支持 Range） |

统一响应体：`{ "code": 0, "message": "ok", "data": {...} }`。

## 4. WebSocket 事件清单（`ws://<host>:8080/ws`）

| type | 触发时机 |
|---|---|
| `alert` | 连接建立（`ws.ready`）、告警推送 |
| `mission.phase` | T0–T7 阶段流转 |
| `mission.progress` | 任务进度百分比变化 |
| `mission.created` | 新任务创建（事件日志） |
| `telemetry.uav.pos` | 无人机位置/轨迹（模拟器或 UDP） |
| `telemetry.link.quality` | 链路质量刷新、一键优化结果 |
| `target.state` | 目标状态变化（红/黄/灰）、打击/升级/观察动作 |
| `node.state` | 节点在线状态（心跳超时判失联） |
| `ai.event` | AI 提示事件（触发语音播报与界面高亮） |
