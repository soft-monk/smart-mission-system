## 1. 语言与前端构建

| 术语 / 工具 | 是什么、干什么用 |
|---|---|
| JavaScript（JS） | 前端唯一通用的脚本语言，语法松散、动态类型。类比：Lua / Python 之于 C++ 程序——但这里是整个前端层的宿主语言 |
| TypeScript（TS） | JS 的超集，加了静态类型系统，编译成 JS 运行。类比：C++ 之于 C——"C + 类 + 模板"增强关系。本项目用它给接口契约（如地图配置）上类型保险 |
| JSX / TSX | 在 JS/TS 源码里直接写类似 HTML 的语法，编译期转换为函数调用。类比：QML / 声明式模板语法；`.tsx` = 含 JSX 的 TS 文件 |
| Node.js | 让 JS 脱离浏览器、在操作系统里独立运行的运行时（自带 V8 引擎 + 系统 API）。前端构建链与服务端工具链都基于它。类比：一个独立的脚本运行平台（如嵌了 LuaJIT 的宿主进程） |
| npm | Node 生态的官方包管理器与注册中心（npmjs.com），负责下载依赖。类比：vcpkg / Conan |
| pnpm | 另一种包管理器，硬链接共享依赖、省磁盘、monorepo 支持好（模板仓库就用它）。类比：Conan 2 的缓存共享 |
| Vite | 前端构建工具 + 开发服务器：开发时秒级热更新，发布时打包压缩产物。类比：CMake + 编译器 + 本地运行循环的合体；"dev proxy"是其内置的请求转发（类比：本地端口转发/反向代理） |
| React | 声明式 UI 组件框架，界面由"组件树"构成，数据变化自动重渲染。类比：Qt Widgets 的地位；React 组件 ≈ 自定义 Widget |
| React Hooks | React 里封装"状态 + 副作用"的函数式写法（如 `useState`、`useEffect`）。类比：把信号槽 + 生命周期管理封装成可复用工具函数；模板的 `use-maplibre` 就是把地图实例封装成 hook |
| Zustand | 极简的前端状态管理库：全局 store + 订阅更新，本项目用它承载 T0–T7 流程状态机与各域状态。类比：一个带变更通知的全局单例对象池 |
| WebSocket 客户端 | 浏览器原生 API：与服务端保持一条长连接，双向收发消息。本项目用它接收实时事件推送。类比：一条持久化的 TCP 长连接 + JSON 帧协议 |
| Storybook | 组件开发与预览工作台。类比：组件库的"演示台/样例浏览器"，本项目建议二期引入 |
| monorepo | 一个 Git 仓库装多个可独立发布的包，统一构建。类比：一个大仓库多个 target/子项目 |
| Apache-2.0 / BSD / MIT | 常见开源许可证：均允许商用与闭源，需保留版权声明（Apache/BSD 另需注意条款细节）。模板仓库为 Apache-2.0，MapLibre 为 BSD |
| zod | JS 运行时数据校验库：对接口返回的 JSON 做"形状+类型"校验再使用。类比：反序列化后先做 schema 校验 |

## 2. 地图与地理

| 术语 / 工具 | 是什么、干什么用 |
|---|---|
| WebGL | 浏览器内的 GPU 图形接口（基于 OpenGL ES）。MapLibre 用它渲染地图。类比：桌面 OpenGL；不支持 WebGL 的环境才需要 Leaflet 兜底 |
| MapLibre GL JS | 开源地图渲染引擎（BSD 协议，Mapbox GL JS v1 的分支），**免 API token**；内置拖拽、滚轮缩放、双击、触屏手势。类比：地图领域的"渲染引擎 SDK" |
| react-map-gl | React 与 MapLibre 之间的适配层，把命令式地图 API 包装成 React 组件。类比：C++ 里给引擎 SDK 套的一层门面（facade） |
| deck.gl | 高性能大数据可视化框架（visgl 出品），在地图之上叠加海量矢量图形（轨迹/热区/锁定框）。类比：额外的"叠层渲染引擎"；本项目 P1 引入 |
| turf | JS 地理空间计算库（距离、缓冲、判断点在面内等）。类比：Boost.Geometry / GEOS 的 JS 版 |
| Leaflet | 极轻量（约 42KB）的地图库，用 DOM/SVG 渲染、**不依赖 WebGL**，只吃栅格瓦片。类比：纯 2D 位图式渲染的 fallback 方案 |
| 栅格瓦片 | 把地图**预渲染成图片**（PNG），按层级/行列切片存储；放大时先显示模糊低层级再替换高清。类比：超大地图的 mipmap 金字塔，每块 256×256 |
| 矢量瓦片 | 不存图片，存几何数据（点线面 + 属性），由客户端实时渲染。本项目二期选项 |
| XYZ 目录 / `{z}/{x}/{y}.png` | 瓦片文件的编号约定：z=层级，x=列号，y=行号（左上角为原点）。类比：资源文件的路径索引约定 |
| zoom level（z3–z15） | 缩放层级：全球在 z 层被切成 `2^z × 2^z` 张瓦片，每升一级瓦片数 ×4。本项目切北京 z3–z15 |
| bbox | 边界框（bounding box）：`[最小经度, 最小纬度, 最大经度, 最大纬度]`。类比：AABB。文档中 `116.05–116.75°E, 39.70–40.15°N` 即北京城区范围 |
| 经纬度（lng / lat） | 地理坐标：经度（-180~180）、纬度（-90~90）。center=[116.39, 39.90] 即北京中心 |
| WGS84（EPSG:4326） | 全球大地坐标系，GPS 所用；Web 数据（GeoJSON 等）的标准坐标系 |
| Web Mercator（EPSG:3857） | 把球面投影到平面的坐标系统，**所有 Web 瓦片都按它切**；MapLibre 自动完成 4326→3857 投影 |
| PMTiles | 把海量瓦片合成**单个文件**的格式（HTTP Range 按需读取）。类比：把整个 mipmap 金字塔打包进一个只读归档文件，分发/备份一个文件搞定 |
| GCJ-02 / BD-09 | 中国国测局/百度的加密偏移坐标（可达数百米）。本项目"全球通用"路线**不涉及** |
| CGCS2000 / 天地图 | 中国 2000 大地坐标系（与 WGS84 厘米级一致，无偏移）；天地图：国家官方地图服务平台（需申请 key） |
| GeoJSON | 地理矢量数据的 JSON 交换格式（RFC 7946）：点/线/面 + 属性 |
| raster style | MapLibre 的样式 JSON：声明数据源类型为栅格（raster）+ 瓦片 URL 模板 |
| attribution（版权标注） | 数据源要求署名的声明，显示在地图右下角。OSM 的**法定义务** |
| OpenStreetMap（OSM） | 全球协作的开源地图数据。类比：开源地图数据集社区 |
| Geofabrik | OSM 数据的区域提取下载站（提供 pbf 格式）。类比：数据镜像站 |
| planetiler | 把 OSM 提取数据离线转成瓦片包的快速工具（Java 实现）。类比：离线"烘焙/预处理管线"，生产合规路线 |
| QGIS | 开源桌面 GIS 软件；本方案用它当"切图 GUI"：加载 OSM 图层后一键导出 XYZ 瓦片目录 |
| OSM Tile Usage Policy | OSM 公共瓦片服务器使用政策：**禁止批量抓取**，仅限开发验证、不得对外分发；生产必须自渲染或用合规源 |

## 3. C++ 后端

| 术语 / 工具 | 是什么、干什么用 |
|---|---|
| Drogon | C++17/20 的**异步非阻塞 Web 框架**（本项目服务端主框架）：内置 HTTP 控制器、WebSocket、静态文件服务、JSON、SQLite ORM。类比：用 C++ 写的"高性能 Web 服务全家桶"（Boost.Asio 之上封装） |
| CMake | C++ 跨平台构建系统（本项目 C++ 后端的构建工具）。类比：就是 CMake 本身，你主场 |
| vcpkg | 微软的 C++ 包管理器：`vcpkg install drogon sqlite3 nlohmann-json` 一条命令拉齐依赖。类比：Conan |
| MSVC / VS2022 | 微软 C++ 编译器与 IDE（Windows 上的构建工具链）。类比：你的日常 |
| nlohmann/json | 头文件式 JSON 库（C++ 世界事实标准），本项目 REST/WS 事件序列化用。类比：你熟悉的 JSON 库之一 |
| sqlite3 | 嵌入式关系数据库（单文件、零服务进程）。类比：把数据库装进一个文件里的轻量存储 |
| WebSocket（服务端） | 服务端与浏览器间的长连接协议：本项目 C++ 网关用它向所有客户端广播事件。类比：多客户端 TCP 长连接 + 帧协议，Drogon 封装好连接管理 |
| UDP 组播 | 一对多的 UDP 传输（同一组播地址的所有订阅者都能收到）。数据链设备用它广播遥测，本项目 C++ 端加入组播组接收 |
| REST / GET / POST | REST：以资源为中心的接口风格；GET=读，POST=写/提交。类比：约定的 RPC 风格 |
| HTTP 状态码 | 响应结果代号（200=成功，404=不存在，500=服务器错误等） |
| 静态托管 | 服务端把磁盘文件（前端产物/瓦片/视频）按 URL 路径原样返回。类比：内置 HTTP 文件服务器 |
| 反向代理 | 服务端把特定前缀请求（`/api/v1/ai/*`）转发给另一个本机进程（Python 桥）并回传响应。类比：本地端口转发/网关 |
| 心跳 / ping-pong | 长连接保活机制：定时小包探测对端存活，超时判定断线。类比：看门狗喂狗 |
| config.json | 服务端 JSON 配置文件（监听地址/端口、组播地址、路径等）。类比：.ini/.cfg |

## 4. Python 与在线 AI

| 术语 / 工具 | 是什么、干什么用 |
|---|---|
| Python | 脚本语言，本项目 AI 桥接服务用它（生态里 AI SDK 最全）。类比：胶水语言，只写薄薄一层转发 |
| FastAPI | Python 的 Web 框架：写几个函数就得到带文档的 HTTP 服务（本项目 AI 桥用）。类比：轻量路由框架 |
| uvicorn | Python 的 ASGI 服务器：`uvicorn app:app --port 8000` 把 FastAPI 跑起来。类比：宿主进程 |
| OpenAI 兼容 API | 一种事实标准的 LLM 调用协议（`/v1/chat/completions` 等端点）。本项目选 OpenAI 系，且兼容协议让供应商可替换 |
| Whisper API | OpenAI 的语音识别接口：音频进、文本出（本项目在线 ASR 用它） |
| TTS API | OpenAI 的语音合成接口：文本进、音频出（本项目在线播报用它） |
| LLM（大语言模型） | 生成式大模型，支撑对话与方案推荐。类比：云端推理服务，按调用量计费 |
| API Key | 调用在线 API 的密钥。**只存在服务端环境变量，绝不进前端代码/浏览器** |
| getUserMedia | 浏览器 API：申请麦克风/摄像头访问权。**要求 secure context**（HTTPS 或 localhost），内网 HTTP 下默认被拒 |
| secure context / HTTPS | 浏览器安全上下文：语音采集的前置条件；内网场景用自签名证书 + 客户端信任导入解决 |

## 5. 接口参数逐字段说明

### 5.1 `GET /api/v1/health` —— 健康检查

| 字段 | 含义 |
|---|---|
| status | 固定返回 `"ok"`，表示服务端已就绪；自检页面据此聚合各模块状态 |
| version | 应用版本号字符串（如 `1.0.0`），供排查与版本信息展示 |

### 5.2 `GET /api/v1/map/config` —— 地图初始化配置

| 字段 | 类型 | 含义 |
|---|---|---|
| center | `[number, number]` | 初始地图中心点，`[经度, 纬度]`（WGS84）。例 `[116.39, 39.90]` = 北京天安门附近 |
| zoom | `number` | 初始缩放层级（11 ≈ 城区街道级） |
| minZoom | `number` | 允许缩到的最粗层级（3，与切片下限一致） |
| maxZoom | `number` | 允许放大的最细层级（15，与切片上限一致） |
| basemap.type | `"raster"` | 底图类型固定为栅格（图片瓦片） |
| basemap.tiles | `string[]` | 瓦片 URL 模板数组；`{z}/{x}/{y}` 是**占位符**，地图库按"层级/列/行"自动替换后取 PNG。例 `/tiles/{z}/{x}/{y}.png` → `/tiles/15/26888/12436.png` |
| basemap.tileSize | `number` | 单张瓦片像素边长（标准 256） |
| basemap.attribution | `string` | 版权署名文本，右下角常显（OSM 合规义务） |

### 5.3 WebSocket 事件（单通道 JSON `{type, data, ts}`）

| type | 含义 |
|---|---|
| telemetry.uav.pos | 无人机位置/轨迹更新 |
| telemetry.uav.status | 无人机状态/电量/在线 |
| telemetry.link.quality | 链路质量（带宽/时延/丢包，1s） |
| target.state | 目标状态（红/黄/灰） |
| mission.phase | T0–T7 流程阶段流转 |
| ai.recommendation | 推荐方案与理由 |
| ai.event | AI 提示事件（触发语音播报/界面高亮） |
| alert | 告警（level: info/warn/critical） |
| node.state | 节点在线状态（心跳超时判定，失联检测依据） |

### 5.4 边界参数（切片范围）

| 参数 | 含义 |
|---|---|
| `116.05–116.75°E` | 北京 bbox 经度范围（约 60km 宽） |
| `39.70–40.15°N` | 北京 bbox 纬度范围（约 50km 高） |
| `z3–z15` | 切片层级：z15 约 2,600 张，累计约 3,500 张、数十 MB；z16 单独约 1 万张，默认不切 |

## 6. 命令与构建速查

| 命令 / 参数 | 干什么用 |
|---|---|
| `pnpm build` | 构建前端（Vite 打包产物，复制到服务端静态目录） |
| `vcpkg install drogon sqlite3 nlohmann-json` | 拉取 C++ 依赖 |
| `cmake -B build -S . && cmake --build build` | 构建 C++ 服务端（VS2022 工具链） |
| `python -m venv .venv` + `pip install -r requirements.txt` | 准备 Python 桥环境 |
| `uvicorn app:app --host 127.0.0.1 --port 8000` | 启动 Python AI 桥（仅本机监听） |
| `mapapp.exe`（或启动脚本） | 启动 C++ 服务端（先起 Python 桥，再起主服务） |
| `server.address=<内网IP>` / `server.port=<端口>` | config.json 配置项：内网监听地址与端口 |
| `{z}/{x}/{y}.png` | 瓦片路径约定（详见第 2 章 XYZ 条目） |
| DevTools Network | 浏览器开发者工具网络面板：核对请求/WS 帧——类比：本页面级抓包工具 |

## 7. 一句话总结本方案的技术地图

```
客户端：任意浏览器（输入内网网址，零安装）——开发期 Chrome/Edge，二期国产化平板浏览器
  界面：React + TypeScript + Vite + Zustand（组件化 UI + 前端状态机）
    地图：react-map-gl + MapLibre GL + deck.gl（WebGL 渲染 + 动态叠层）
      数据：服务端本地托管的预切瓦片 XYZ（预烘焙金字塔，局域网毫秒级）
  实时：浏览器 WebSocket（订阅服务端事件广播）
  视频：<video> 直接播放服务端静态 mp4（无网关无转码）
服务端：一台主机集中部署
  主服务：C++ Drogon（HTTP + WS 网关 + UDP 组播接入 + SQLite + 静态托管）
  AI 桥：Python FastAPI（仅本机）→ OpenAI 系在线 API（LLM / Whisper ASR / TTS）
```

C++ 工程师最小认知集：**B/S=服务端集中+浏览器访问、Drogon=C++ Web 服务框架、React=UI 组件化、MapLibre=地图渲染引擎、WebSocket=实时推送长连接、UDP 组播=数据链入口、瓦片=预渲染图片金字塔、Python 桥=在线 AI 的转发层**，其余条目随用随查即可。
