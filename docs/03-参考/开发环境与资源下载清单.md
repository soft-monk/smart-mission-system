## 2. 地理数据资源

### 2.1 北京城区栅格瓦片（P0，服务端瓦片数据）

| 方式 | 说明 | 地址/命令 | 合规注意 |
|---|---|---|---|
| A. QGIS 导出（推荐，免写脚本） | QGIS 添加 XYZ Tiles 图层（OSM 源：`https://tile.openstreetmap.org/{z}/{x}/{y}.png`）→ 缩放到北京 bbox（116.05–116.75°E, 39.70–40.15°N）→ 右键图层「导出 → 生成 XYZ 瓦片（目录）」→ 选 z3–z15 | QGIS 官方下载见上 | 遵守 [OSM Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/)：**禁止批量抓取、仅限开发验证、不得对外分发** |
| B. 脚本抓取（备选） | 按 bbox 逐层下载 PNG（限速 ≤ 1 张/秒、限并发、设置 User-Agent） | 瓦片服务：`https://tile.openstreetmap.org/{z}/{x}/{y}.png` | 同上；生产必须自渲染（planetiler）或合规数据源 |
| C. 现成 MBTiles → 转 XYZ（备选） | 若已有 MBTiles 文件，用 mbutil 解包为 XYZ 目录 | https://github.com/mapbox/mbutil | 数据来源许可需自行核对 |

> 产出目录结构：`tiles/{z}/{x}/{y}.png`，z3–z15 约 3,500 张、数十 MB。

### 2.2 三维数据 —— 已取消（v1.2 范围收敛）

> **不再需要**：需求已放弃全部三维能力（场景三与 2D/3D 切换、三维地形、三维建筑、楼层/室内），因此**原「地形 DEM」与「建筑矢量」两节整体取消**——无需下载 SRTM/ALOS DEM，无需 OSM 建筑矢量与 fill-extrusion 挤出，也无需 terrain-rgb 转换工具。
>
> 保留记录：原计划使用 SRTM GL1 / ALOS AW3D30（30m）经 GDAL/rio-rgbify 转 terrain-rgb 瓦片，建筑用 Geofabrik 中国区域 OSM pbf 挤出。若日后恢复三维（参见需求初稿附录 A/B），再按上述路径重新准备；注意届时渲染引擎可能需要真三维方案（如 Cesium），MapLibre flat + deck.gl 不足以承载。
