## 1. 范围与硬约束

| 约束 | 内容 | 依据 |
|---|---|---|
| 渲染维度 | **仅二维**：MapLibre flat（Web Mercator 平面），不做 2D/3D 切换、不做三维地形/建筑 | 初稿附录 A/B；TRD D12 |
| 使用区域 | 全球通用（WGS84 / Web Mercator），无 GCJ-02 偏移 | TRD D2 |
| 底图数据 | 预切**栅格瓦片**（XYZ 目录）服务端本地托管，北京 z3–z15 起步；在线源按需可选 | TRD D5 / GEO-01 |
| 数据来源 | 当前实现为 Esri World Imagery（署名 Esri / Maxar / Earthstar Geographics）；已打包 `tiles-v1` Release 分发 | 下载清单 §2.1 / Release `tiles-v1` |
| 运行形态 | B/S：服务端托管瓦片与前端，浏览器渲染；**只有服务端需要瓦片** | TRD §1.2 |
| 网络前提 | 终端可联网，但**地图重资源本地化**以保证流畅（断外网时地图仍可用） | TRD D1 / NFR-02 |
| 性能基线 | 拖拽/缩放/动态图层更新无明显卡顿；局域网毫秒级瓦片加载 | NFR-01 |

## 7. 数据与接口约束

| 项 | 约定 | 来源 |
|---|---|---|
| 底图配置接口 | `GET /api/v1/map/config` → `{ center:[lng,lat], zoom, minZoom, maxZoom, basemap:{ tileUrlTemplate, attribution }, video?:[] }`（**无 terrain / 3dtiles 字段**） | 契约 §3 |
| 瓦片路径 | `/tiles/raster/{z}/{x}/{y}.jpg`，静态托管支持 Range；**响应头带 `Cache-Control: public, max-age=31536000, immutable`**（瓦片按 URL 永不变更；`index.html` 不加，避免更新后吃旧壳） | 契约 §1 |
| 坐标系 | 数据 WGS84；瓦片 Web Mercator；MapLibre 自动投影 | TRD D2 |
| 缺瓦片降级 | ① 低清叠底（z0–6，全球覆盖，常驻）先把该区域画出来；② 仍无数据处露缺口底色（深蓝灰，非黑）；③ 矢量图层（轨迹/目标/链路/区域）始终在底图之上，演示不受阻 | 契约 §9 |
| 版权标注 | 由 `map-2d/src/core/options.ts` 的 `MAP_OPTIONS.showAttribution` 控制（默认 **false**＝不显示，同时不写入 `source.attribution`）；恢复署名只需把该开关改回 `true` | GEO-05 |
| 瓦片分发 | 单包 zip 经 `install_tiles.bat` 安装，或 `fetch_tiles.bat` 按需抓取；Release `tiles-v1`（14,204 张 / 172.3 MB） | 下载清单 §6.1 |
| 与实时通道的关系 | 地图动态图层的数据来自 WebSocket 事件：`telemetry.uav.pos`、`telemetry.link.quality`、`target.state`、`mission.phase` 等 | TRD §5.2 |

## 11. 地图模块与集成边界（实现结构）

二维地图已抽为**独立模块** `map-2d/`（可独立启动、可整包交付、可发布为自己的子仓），
主系统通过别名 `@map2d` 消费它——**用法与调用第三方库一致**：

```
map-2d/
├─ index.html                  # 独立宿主页面（npm run dev → http://localhost:5180/）
├─ README.md                   # 模块说明：API / 绘制能力 / 独立启动 / 交付方式
└─ src/
   ├─ index.ts                 # 唯一公开入口
   ├─ core/                    # types（自带契约）/ instance / commands（视角 API）/ store / displayMode / options
   ├─ primitives/api.ts        # ★ 绘制 API：MapDraw（9 类图元的增删改查、导入导出）
   ├─ render/LayerManager.ts   # 底层图层与 source 管理 + 图层分组显隐
   ├─ ui/                      # MapView / MapToolbar / LayerPanel / Compass / MapModeBadge
   └─ standalone/              # 独立宿主入口 + 示例数据 + 独立样式
```

**两种运行形态（同一份代码）**

| 形态 | 启动方式 | 用途 |
|---|---|---|
| 嵌入式 | 主系统 `frontend` 经 `@map2d` 别名引入 | 生产系统（T0–T7 界面内） |
| **独立运行** | `cd map-2d && npm install && npm run dev` → `http://localhost:5180/` | 演示/自检/交付给别人；**不依赖后端与主系统**，示例图元来自 `standalone/demo-data.ts` |

**依赖规则**：模块只依赖 `maplibre-gl` / `react` / `zustand`；**不依赖**主系统的 store、面板、组件库或后端。
主系统侧唯一连接点是 `frontend/src/app/useMapData.ts`（业务 store → `MapData` 适配器）。

**绘制能力（渲染 + API 驱动）**：`MapDraw.set/add/remove/clear/list/export/load`，
覆盖 `area / drone / target / link / track / scan / pulse / cluster / label` 九类图元；
样式与数据解耦（图元自带 color/label/status/threat/state，未给则用内置调色板）；
换底图后自动重建图层并重放图元。**手绘交互（鼠标绘制）不在本版本范围。**

**清屏的职责划分**：开关在模块（工具条【清屏】+ `useMapUiStore.clearMode`）；
"隐藏哪些区域"由应用框架决定（`app/AppShell.tsx` 按 `clearMode` 条件渲染）。

**子仓交付**：`scripts\publish-map2d.bat` 用 `git subtree split --prefix=map-2d`
生成只含本模块的历史并推送到独立仓库（默认 `soft-monk/map-2d`），主仓结构不变、模块可被单独 clone。
