## 2. 地理数据资源（P0 瓦片现在要；DEM 可 P1 前提前准备）

### 2.1 北京城区栅格瓦片（P0，服务端瓦片数据）

| 方式 | 说明 | 地址/命令 | 合规注意 |
|---|---|---|---|
| A. QGIS 导出（推荐，免写脚本） | QGIS 添加 XYZ Tiles 图层（OSM 源：`https://tile.openstreetmap.org/{z}/{x}/{y}.png`）→ 缩放到北京 bbox（116.05–116.75°E, 39.70–40.15°N）→ 右键图层「导出 → 生成 XYZ 瓦片（目录）」→ 选 z3–z15 | QGIS 官方下载见上 | 遵守 [OSM Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/)：**禁止批量抓取、仅限开发验证、不得对外分发** |
| B. 脚本抓取（备选） | 按 bbox 逐层下载 PNG（限速 ≤ 1 张/秒、限并发、设置 User-Agent） | 瓦片服务：`https://tile.openstreetmap.org/{z}/{x}/{y}.png` | 同上；生产必须自渲染（planetiler）或合规数据源 |
| C. 现成 MBTiles → 转 XYZ（备选） | 若已有 MBTiles 文件，用 mbutil 解包为 XYZ 目录 | https://github.com/mapbox/mbutil （Python，需本机装 Python） | 数据来源许可需自行核对 |

> 产出目录结构：`tiles/{z}/{x}/{y}.png`，z3–z15 约 3,500 张、数十 MB。

## 4. 国内网络加速与镜像（下载期使用，不改变任何选型）

### 4.1 依赖镜像

| 对象 | 配置方法 |
|---|---|
| npm / pnpm | `npm config set registry https://registry.npmmirror.com`（pnpm 同源：`pnpm config set registry ...`）；官方镜像站：https://npmmirror.com |
| Maven | 编辑 `%USERPROFILE%\.m2\settings.xml` 加阿里云镜像：`https://maven.aliyun.com/repository/public`（配置说明：https://developer.aliyun.com/mvn/guide ） |

### 4.2 模型下载

| 对象 | 配置方法 |
|---|---|
| HuggingFace 模型 | 国内替代镜像：https://hf-mirror.com （设置 `HF_ENDPOINT=https://hf-mirror.com`） |
| 国内模型源 | ModelScope（魔搭）：https://modelscope.cn （sherpa-onnx 中文模型、Qwen 等均有镜像，推荐优先用） |

### 4.3 GitHub 加速

- 克隆仓库慢时可用系统代理；第三方 ghproxy 类加速站风险自担，**不建议在生产链路使用**
- 各工具官方均提供预编译 release 资产，优先直接下载 release 文件而非 clone 源码
