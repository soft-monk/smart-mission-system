# 智能任务管理系统（mapApp）

内网 Web 应用（B/S）：**一台主机部署服务端，其他电脑/平板通过浏览器输入网址访问操作，客户端零安装**。技术栈：**React/TypeScript + MapLibre GL（+deck.gl）+ Java Spring Boot + MQTT + C++ 性能模块**（视频/语音/推理）。

## 目录结构

```
mapApp/
├─ docs/                     # 全部文档（分类安放）
│  ├─ 01-需求/               # 界面与流程需求初稿（产品需求源，只读）
│  ├─ 02-技术需求/           # 技术需求文档（研发实施依据，含分阶段验证 P0–P4）
│  ├─ 03-探讨/               # 技术路线与方向探讨（决策过程存档）
│  ├─ 04-参考/               # 术语与工具速查、开发环境与资源下载清单
│  └─ 05-设计/               # 概要设计文档（架构级：怎么做）
├─ frontend/                 # React + TypeScript（Vite，浏览器渲染）
│  └─ src/{api,map,layers,stores,app}
├─ backend/                  # Java Spring Boot 服务端
│  └─ src/main/{java/com/mapapp/..., resources/static}
├─ tiles/                    # 离线瓦片数据（raster/dem/3dtiles/vector；二进制不入库）
├─ scripts/                  # 构建与部署脚本
└─ release/                  # 服务端部署包输出（不入库）
```

## 构建与部署流水线（B/S）

```
frontend: pnpm build → 产物复制到 backend 静态目录
backend:  mvn package → fat-jar（服务端）
部署:     java -jar + 静态资源 + 瓦片 → 服务端部署包（release/）
客户端:   浏览器访问 http://<服务端内网IP>:<端口>/，零安装、零升级
```
